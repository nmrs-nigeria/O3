# Contributing to NMRS Form Converter

Thank you for your interest in contributing to the NMRS Form Converter project!  
Your help is welcome and appreciated.

---

## How to Contribute

### 1. Fork the Repository

- Click the "Fork" button at the top right of the repository page.
- Clone your fork to your local machine:

  ```bash
  git clone https://github.com/yourusername/NMRSFormConverter.git
  cd NMRSFormConverter
  ```

### 2. Create a Branch

- Create a new branch for your feature or bugfix:

  ```bash
  git checkout -b my-feature
  ```

### 3. Make Your Changes

- Write clear, well-documented code.
- Follow the existing code style.
- Add or update tests if applicable.

### 4. Test Your Changes

- Make sure the application runs and your changes work as expected.
- Run the app with:

  ```bash
  python NMRSFormConverter.py
  ```

### 5. Commit and Push

- Commit your changes with a descriptive message:

  ```bash
  git add .
  git commit -m "Describe your change"
  git push origin my-feature
  ```

### 6. Open a Pull Request

- Go to your fork on GitHub and click "Compare & pull request".
- Describe your changes and submit the pull request.

---

## Code of Conduct

- Be respectful and constructive.
- Write clear commit messages and pull request descriptions.
- Ask questions if you are unsure about anything.

---

## Reporting Issues

- Use the GitHub "Issues" tab to report bugs or request features.
- Provide as much detail as possible (steps to reproduce, environment, etc.).

---

## Need Help?

- Open an issue or contact the maintainer.

---

Thank you for helping improve NMRS Form Converter!
